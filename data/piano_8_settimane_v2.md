# Piano 8 Settimane v2 — Bilanciere-First

> Beach Volley Strength & Conditioning, palestra nuova. 8 settimane, nessuna identica all'altra.

## Parametri

| Parametro | Valore |
|-----------|--------|
| Periodo | Lun 28 set → Dom 22 nov 2026 |
| Obiettivo | Forza + potenza per beach volley |
| Frequenza pesi | 3x/settimana |
| Frequenza beach | 2x fissa (Mer + Gio) + 3° nel weekend se capita |
| Durata seduta | ~60 min |

| Assente | KB, trap-bar, assault bike, wall ball, anelli |

## Come Funziona Questo Piano

**5 anchor fissi** restano identici per 8 settimane, così la progressione è misurabile: Back Squat, Bench Press, Deadlift, Overhead Press, Pull-up.

**Tutto il resto ruota**: variante dello stesso pattern, accessori, tirate, prehab, conditioning. Nessuna settimana ripete la combinazione della precedente. Ogni settimana ha un tema con un nome.

## Settimana Tipo

| Giorno | Attività |
|--------|----------|
| Lunedì | **A — Lower Power** (squat) |
| Martedì | Riposo |
| Mercoledì | Beach |
| Giovedì | Beach |
| Venerdì | **B — Upper + Pull** (panca, OHP) |
| Sabato | **C — Hinge + Power** (stacco, clean) |
| Domenica | Riposo, o C se sabato salta |

**Perché questo ordine**: dopo due giorni di beach il venerdì tocca alla B, l'unica seduta senza lavoro pesante sulle gambe. Lo stacco del sabato arriva con un giorno di recupero dalla sabbia e resta a 48h dallo squat del lunedì; lo squat resta a 48h dal beach di mercoledì, con il martedì di riposo in mezzo. Se la C slitta a domenica, il lunedì dopo tieni lo squat a RPE basso: sono due sedute di gambe di fila.

### Regola C-Lite

Se nel weekend giochi a beach, la seduta C diventa **C-Lite**: togli stacco pesante, clean e salti. Tieni Overhead Press, tirata, core e conditioning in zona 2. Non salti la seduta, la svuoti delle cose che ti costano in sabbia.

### Regola Beach > Pesi

Il beach vince sempre. Se la sabbia ti ha distrutto: taglia i set sugli accessori, tieni gli anchor anche a -10% di carico, elimina il conditioning. Se sei cotto per due sedute di fila, salti C per prima — è la più sacrificabile.

## Progressione Anchor

Top set + back-off. Il top set trova il carico, i back-off accumulano volume al -10% con tecnica pulita.

| Settimane | Fase | Top Set | Back-off |
|-----------|------|---------|----------|
| 1-2 | Base | 1x5 @RPE 7-7.5 | 3-4x5 @-10% |
| 3 | Tempo | 1x5 @RPE 8 | 3x5 @-10% |
| 4 | Test | 3RM | 2x3 @-20% |
| 5 | Intensificazione | 1x3 @80% | 3x4 @-10% |
| 6 | Intensità | 1x3 @87% | 2x3 @-10% |
| 7 | Qualità | 1x3 @85% | 2x3 @-10% |
| 8 | Deload | 3x5 @60-65% | — |

**Regole**:
1. RPE ≤ target → +2.5kg upper, +5kg lower la settimana dopo
2. RPE sopra target → carico fermo, non scendere
3. Tecnica crolla → riduci del 5% e lavora sul punto debole
4. Mai cedimento. Mai RIR 0.

### Warm-up Standard (6 min, uguale ogni seduta)

1. 1' cyclette o camminata
2. Mobilità caviglia: wall drill 10/lato
3. Affondo dinamico + rotazione toracica 5/lato
4. Squat corpo libero 10 fluide
5. Band pull-apart 15 (solo seduta B)
6. 2-3 serie di avvicinamento al primo esercizio pesante

## Pool di Esercizi — Tecnica

### Potenza
| Esercizio | Tecnica chiave |
|-----------|----------------|
| **CMJ** | Contro-movimento rapido, estensione massima, atterraggio morbido. Conta l'altezza, non la fatica |
| **Approach Jump** | 2-4 passi di rincorsa, stacco deciso come su un attacco |
| **Box Jump** | Atterra sul box in squat, scendi camminando. Mai saltare giù |
| **Hang Power Clean** | Hip hinge → esplosione delle anche → catch in quarter squat. Il bilanciere resta vicino |
| **Clean Pull** | Stessa spinta del clean senza il catch. Utile quando la tecnica di catch non è affidabile |
| **High Pull** | Doppia estensione, poi tirata alta con i gomiti |

### Lower
| Esercizio | Tecnica chiave |
|-----------|----------------|
| **Back Squat** | Parallelo o sotto, ginocchia che seguono i piedi, core tight |
| **Front Squat** | Gomiti alti, busto verticale, bilanciere sulle clavicole |
| **Tempo Squat** | Conta i secondi: discesa, fermo, salita. Non barare sul ritmo |
| **Pause Squat** | 2" di fermo vero in buca, senza molleggiare |
| **Box Squat** | Seduta completa sul box, poi esplosione. Insegna a partire dal basso |
| **RDL** | Hip hinge, ginocchia semi-flesse, senti i femorali, schiena neutra |
| **Stacco con deficit** | 5cm di rialzo, più ROM. Carico più basso, non negoziare |
| **Hip Thrust** | Scapole sul bordo, spingi con i talloni, squeeze 1" in alto |
| **Bulgarian Split Squat** | 90% del peso sulla gamba avanti, ginocchio tracking |
| **Step-up** | Spingi con la gamba sopra, non slanciarti. Controlla la discesa |
| **Affondo camminata** | Passo medio, ginocchio non oltre le punte in modo aggressivo |

### Upper
| Esercizio | Tecnica chiave |
|-----------|----------------|
| **Bench Press** | Scapole addotte, arco toracico, tocca il petto controllato |
| **Pause Bench** | Fermo al petto, niente rimbalzo |
| **Close-grip Bench** | Presa ~30cm, gomiti vicini al corpo |
| **Floor Press** | Da terra, gomiti a 45°, stop a terra. Toglie il leg drive |
| **Overhead Press** | Core tight, no lean back eccessivo, lockout completo |
| **Push Press** | Piccolo dip delle gambe, spinta, lockout. Controllato |
| **Pendlay Row** | Ogni rep riparte da terra, tirata esplosiva all'ombelico |
| **Bent Over Row** | Busto a 45°, tira verso l'ombelico, squeeze scapole |
| **Inverted Row** | Corpo rigido come una tavola, petto alla sbarra |
| **Pull-up** | Dead hang, petto alla sbarra, negativa controllata |
| **Face Pull** | Tira verso la faccia, extrarotazione finale, squeeze |

## Gestione Fatica

### Segnali che stai esagerando
- L'RPE sale senza che il carico salga
- L'altezza del salto cala di sessione in sessione
- Sonno o umore compromessi
- La motivazione è a zero per più di due sessioni

**Azione**: mini-deload di 3-4 giorni (volume -50%, carichi -20%) oppure salti una seduta C. Non tirare dritto.

### Ordine di taglio quando sei cotto
1. Conditioning (si elimina per primo, sempre)
2. Accessori e unilaterali (-1 set)
3. Prehab (resta solo face pull)
4. Back-off degli anchor (-1 set)
5. **Mai** il top set degli anchor, mai i salti

### Acqua, sonno, sabbia
Il piano non funziona se dormi 5 ore. Se il beach è intenso, il volume in palestra scende, non sale.
